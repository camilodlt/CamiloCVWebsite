abstract: The problem of program synthesis involves automatically finding a function based on evaluation criteria, such as matching input-output pairs. While Cartesian Genetic Programming has excelled in various function synthesis tasks, it has primarily been limited to single data types, reducing its applicability to more diverse data. This work introduces Multimodal Adaptive Graph Evolution (MAGE), a generalized extension of Cartesian Genetic Programming that integrates functions of different data types by grouping them accordingly and imposing type-aware mutation constraints. Comparisons with standard CGP and Mixed-Type CGP on program synthesis benchmarks and image classification tasks show that MAGE facilitates the search for multimodal functions.
