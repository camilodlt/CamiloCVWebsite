abstract: |-
  Cartesian Genetic Programming is a graph-based evolutionary representation in
  which candidate solutions are encoded as a directed acyclic grid of
  computational nodes. In standard Cartesian Genetic Programming, only the
  output of the full graph is considered for fitness evaluation, although all
  intermediary active node outputs are computed during execution. This paper
  introduces Iterative Subgraph Assessment CGP, a simple extension that treats
  every active node output as a potential solution: during each individual
  evaluation, all subgraph outputs are assessed alongside the full graph, and
  the best-performing expression is selected. This modification aims to exploit
  useful intermediate computations that would otherwise be ignored.
