abstract: The use of artificial intelligence in critical applications can be limited due to a lack of model understanding. Genetic programming offers an alternative to black-box methods like deep neural networks by evolving interpretable function representations. This chapter presents recent advances in the application of genetic programming to biomedical data analysis, focusing on the challenges of evolving interpretable models for real-world datasets. It details Kartezio, a Cartesian Genetic Programming approach for biomedical image segmentation, showing that it can achieve competitive performance with state-of-the-art deep learning methods while requiring much smaller annotated datasets. It also explores active-learning-based data sampling for small labeled datasets and introduces the Multimodal Active Genetic Evolution algorithm, which extends Cartesian Genetic Programming to handle multiple data types. Overall, the chapter shows how genetic programming can support high-dimensional biomedical data analysis with interpretable models suitable for critical applications.
