abstract: Multimodal Adaptive Graph Evolution is a multi-chromosome generalization of Cartesian Genetic Programming that groups functions by return type and constrains graph mutation based on node type coherence. This paper studies MAGE for program synthesis and evaluates it on the Program Synthesis Benchmark Suite. The results show that MAGE explores the solution space more effectively by creating candidate solutions with lower semantic redundancy.
